# iris_classification
# Iris Classification using KNN

This project uses the Iris dataset to build a classification model using the K-Nearest Neighbors (KNN) algorithm.

## Features
- Data preprocessing
- Feature scaling using StandardScaler
- Train/Test split
- KNN classification
- Confusion Matrix
- F1 Score evaluation

## Technologies
- Python
- Scikit-learn
- Pandas
